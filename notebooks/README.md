# Notebooks

| Notebook | When | Open it |
|---|---|---|
| [`00_preflight_check.ipynb`](00_preflight_check.ipynb) | Before class, about 5 minutes: checks that Colab can run the lab on your account | [Open in Colab](https://colab.research.google.com/github/Sushanth-Manakhari/generative-models-aerial-imagery/blob/main/notebooks/00_preflight_check.ipynb) |
| [`01_generative_roofs_lab.ipynb`](01_generative_roofs_lab.ipynb) | In class, 90 minutes: ROOF-301 to ROOF-304, five short exercises and the modern fixes | [Open in Colab](https://colab.research.google.com/github/Sushanth-Manakhari/generative-models-aerial-imagery/blob/main/notebooks/01_generative_roofs_lab.ipynb) |

In Colab, choose **Runtime → Change runtime type → T4 GPU → Save** first, then run the cells from the top with
**Shift + Enter**. Nothing needs to be installed on your laptop. Without a GPU, the lab loads ready-made models
(release `models-v1`) instead of training them.

To run them on your own laptop instead, follow [../docs/SETUP.md](../docs/SETUP.md) and open them in JupyterLab.
